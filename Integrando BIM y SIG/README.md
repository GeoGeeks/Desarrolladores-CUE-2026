# Integrando BIM y SIG

## ArcGIS SDK para Unity: Integrando BIM y GIS en experiencias inmersivas

Este proyecto presenta una experiencia 3D interactiva desarrollada en Unity, integrando información BIM y SIG para representar una infraestructura de cable aéreo dentro de un entorno geográfico e inmersivo.

El objetivo es demostrar cómo los modelos de infraestructura pueden combinarse con información geoespacial y Unity para crear experiencias interactivas y de realidad virtual.

## Tecnologías utilizadas

- Unity
- C#
- ArcGIS Maps SDK for Unity
- ArcGIS
- ArcGIS Pro
- BIM
- Modelos 3D
- Realidad Virtual
- OpenXR

## Descripción del proyecto

El proyecto representa una infraestructura de cable aéreo mediante modelos 3D integrados en Unity.

La experiencia permite al usuario:

- Visualizar la infraestructura.
- Recorrer el sistema de cable aéreo.
- Interactuar con la cabina.
- Abrir y cerrar las puertas.
- Ingresar a la cabina.
- Realizar el recorrido.
- Experimentar la infraestructura mediante realidad virtual.

## Flujo general

El flujo utilizado para desarrollar la experiencia es:

BIM → SIG → Unity → Realidad Virtual

Los modelos de infraestructura se preparan y organizan para posteriormente integrarlos dentro de Unity junto con el contexto geográfico.

Unity se utiliza como plataforma para construir la experiencia interactiva y de realidad virtual.
